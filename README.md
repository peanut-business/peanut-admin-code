# Peanut Admin Code

This repository is the Peanut Admin product application source repository.

Project documentation, architecture, development rules, plans, product status and release governance are maintained in `peanut-business/peanut-admin-project`. Normal development checks out the Project and Code repositories side by side and uses `dev` as the integration branch.

`main` is release-only. Runtime/build manifests, lock files, source code, tests, deployment definitions, scaffold sources and distribution/legal artifacts remain in this repository.
