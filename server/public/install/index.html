READY TO GO

一切就绪，欢迎使用。

你的应用已完成初始化。现在可以使用刚刚创建的管理员账号，开始配置和使用管理后台。

进入管理后台 →
接下来可以做什么？

完善应用信息，按需启用功能模块，并邀请团队成员。

1. 使用安装时创建的平台管理员账号，在已配置的平台访问地址打开 /platform/。请保留部署时的实际协议与端口。

2. 在“租户运营 → 入口域名与客户端”选择初始 default 租户，填写已指向此应用的租户域名，客户端选择“管理端网页”（admin-web），填写变更原因并启用绑定。租户域名须与平台域名分开。

3. 在绑定的租户访问地址打开 /admin/login，使用安装时创建的应用管理员账号登录。

安装入口已锁定，已有数据与管理员身份会被保留。
