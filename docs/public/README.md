# Peanut Admin 使用资料

本目录随产品源码和固定发行包提供，面向部署者、模块开发者与 API 使用者。它不依赖维护者的私有 Project 仓库。

- [发行渠道与版本身份](release-channels.md)
- [API 合同与 SDK](api-and-sdk.md)
- [模块开发与交付](module-development.md)

发行包应同时包含根目录的 `README.md`、许可证及第三方告知、固定依赖锁、`server/generated/openapi.json`、生成的 SDK 类型，以及安装和独立升级工具。文档中的版本以所在发行包的 `release-versions.json` 和发行清单为准；阅读旧发行包自带的旧文档不构成漂移。
