# 支持与问题报告

普通缺陷、资料错误和兼容问题使用APP或对应组件仓的问题入口。报告实际APP版本、上游来源、commit/tree、Edition、模块、最小复现、预期/实际结果、错误码及退出状态；明确未执行的检查。不上传客户源码、数据库、环境文件、原始日志、凭据、Cookie、令牌或完整资源登记。

越权、跨租户、秘密泄露、任意文件或代码执行及完整性绕过使用私有漏洞报告。没有私有入口时，只发不含漏洞细节的安全联络请求和私下联系方式；建立私有渠道后再交必要脱敏资料，不在公开Issue附攻击步骤或诊断包。

诊断仅输出有界版本、模块及状态，审查内容与摘要后再分享。源码、构建或模拟测试不证明真实数据库、浏览器、恢复或生产资格。只测试自己拥有或明确获准的系统和数据。
