# Getting started

Copy root `.env.example` to `.env` for Docker ports, images and build proxies only. Copy `server/.env.example` to permission-0600 `server/.env`; it is the single source for PHP, database and Tenant/Platform runtime settings. `PHP_*` backend aliases are forbidden. Register this application's own database, ports, domains and external services in `resources/project-resources.json` before connecting anything.

Install the adopted scaffold major only into a confirmed empty database. Write `ADMIN_INITIAL_EMAIL` and a strong `ADMIN_INITIAL_PASSWORD` to a separate permission-0600 one-time file, select it with `PEANUT_INSTALLATION_ENV_FILE` only for `php server/database/install.php`, then delete it. Run `php server/database/environment-guard.php --current` afterward. Later scaffold patch/minor releases use the standard update path and apply append-only files in `server/database/migrations/`; a different scaffold major requires a specifically supported migration and verified backup; otherwise the upgrade must stop. Never use --fresh to overwrite an existing customer database. The application's own product version is independent and does not trigger this scaffold-major rule.
