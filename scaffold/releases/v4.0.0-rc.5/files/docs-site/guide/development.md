# 开发约定

应用维护者拥有自己的业务和扩展；上游技术 Core 与官方模块按正式版本提供。新增功能优先走 Controller → 明确用例服务 → 所属模块数据与公开依赖，沿用框架容器、Validator、ORM、事务和中间件。

只声明需要的对象、允许输入、动作和输出。可信租户/人员来自执行上下文，不能由表单 `tenant_id` 替代；服务级权限覆盖 CLI/Worker，模型 Scope 不保护任意原始 SQL。Model 不跨操作共享记录状态，Validator 每次使用干净实例。

修改实现时同步公开合同、文档/SDK、生成器及受影响测试。正常、拒绝、失败恢复均须验证；生产发布与本地开发是不同授权。应用自有代码/秘密不由框架升级覆盖。

从 [生命周期指南](application-module-lifecycle.md) 创建应用、开发/打包模块、在独立应用中安装并验证升级；用 [参考](../reference.md) 查看命令和失败边界。
